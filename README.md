# Deep History

A human history simulator. It starts in **15,000 BCE** with Late Stone Age foragers. After that, nothing is scripted: farming, cities, states, languages, religions, wars and historical figures all emerge from the simulation. You can run it on approximate Earth or on a generated world.

## Download & run

Grab the latest build from **[Releases](../../releases)**:

| Platform | File | Notes |
|---|---|---|
| Windows | `DeepHistory-*-win-x64.exe` (portable) or the `Setup` installer | Unsigned: on the SmartScreen warning, click *More info → Run anyway* |
| macOS | `DeepHistory-*-mac-*.dmg` | Unsigned: right-click the app → *Open* the first time |
| Linux | `DeepHistory-*-linux-x86_64.AppImage` | `chmod +x` it, then run |
| Any browser | `DeepHistory.html` | Single offline file; just double-click it |

## Build from source

```bash
npm install
npm start                     # build the page and launch the desktop app
npm run dist                  # build an installer/executable for your OS into release/
node test/run.mjs earth 2000  # headless run: 2,000 simulated years, prints stats and major events
```

To publish a new release, push a version tag (for example `git tag v0.2.0 && git push --tags`). GitHub Actions then builds the Windows, macOS and Linux executables and attaches them to the release.

## What is simulated

- **Climate**: orbital forcing drives ice sheets, and ice volume sets sea level, which opens and drowns land bridges. Meltwater can shut down the ocean overturning circulation, causing abrupt northern cold snaps. Monsoons follow insolation, with a vegetation feedback that greens and dries deserts. On top of that sit millennial, solar, ENSO-like and decadal regional oscillations, plus random volcanic eruptions. Plant productivity comes from the Miami model.
- **Population**: a calorie economy of foraging, fishing, farming and herding. Game can be overhunted (megafauna extinctions), forests must be cleared for fields, and soils deplete or turn salty. Births and deaths respond to hunger, crowding and disease. People migrate, crossing seas once they have boats.
- **Disease**: crowd diseases jump from domestic animals to people in dense populations. They spread by contact, become endemic once a community is large enough to sustain them, grow milder over time, and devastate populations that have never been exposed.
- **Culture, language, religion**: cultures are vectors of 10 values that drift and adapt (for example, the plough pushes toward patriarchy and herding toward honour cultures). Languages are generated with their own sounds and vocabulary, undergo regular sound changes and word replacement, and borrow from neighbours. Smaller groups shift to dominant languages (Abrams–Strogatz model). Folk religions become temple cults; prophets appear in crises; faiths spread by conversion and split in schisms.
- **Technology**: 59 inventions, each needing earlier steps and local resources. Larger connected populations invent more (with diminishing returns), ideas spread through contact, and small isolated groups can lose skills.
- **People**: personalities (Big Five, partly inherited, shaped by culture), plus skills, ambition, piety, goals, memories and opinions of each other. Families and dynasties; life expectancy uses a real pre-modern mortality model.
- **Organizations**: tribes, chiefdoms, kingdoms, empires, churches, guilds, merchant houses, banks, bandit gangs, religious orders and mercenary companies. Inside each, officials form factions, foreign rulers back them, and the result can be coups, purges, regencies, succession wars, secession or personal unions.
- **Diplomacy & war**: each ruler weighs personality against the balance of power (a Lanchester-style odds calculation). The options are war, raids, demands for tribute, alliances (honoured or betrayed), royal marriages, trade, loans and defaults.
- **God tools**: impose droughts, plagues, prophets or supervolcanoes; warm or cool the planet; reveal technologies; strike down rulers; spark revolts.

## Layout

`src/` simulation engine · `ui/` browser interface · `app/` desktop wrapper (Electron) · `data/earth.json` Earth heightmap (generated by `tools/earth.py`) · `test/` headless runners
